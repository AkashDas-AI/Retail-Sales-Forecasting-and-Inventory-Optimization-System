# Trained Models Directory

This directory stores serialized model artifacts, training checkpoints, and model metadata generated by the forecasting engine (e.g., LightGBM booster files, scikit-learn pipeline objects, scalers).

## Guidelines
- Trained binary artifacts (`*.joblib`, `*.pkl`, `*.bin`) should generally be excluded from git version control via `.gitignore`.
- Model metadata, schema signatures, and evaluation scorecard JSONs may be version-controlled if lightweight.
